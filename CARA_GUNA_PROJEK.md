# SENSEI BM - Panduan Projek Penuh (Luar Talian & Pembangunan)

Aplikasi Pembelajaran Bahasa Melayu Berasaskan Komik & Manga untuk Sekolah Rendah (Tahap 1 & 2).

---

## 📁 Kandungan Fail ZIP Ini

1. **`dist/` (Fail Web Siap Bina - Boleh Dihoskan Terus)**
   - Mengandungi fail `index.html`, fail `assets/`, gaya CSS, dan skrip JavaScript yang telah dikompilasi secara optimum.
   - Boleh terus dimuat naik ke mana-mana hosting (Vercel, Netlify, cPanel, Firebase, GitHub Pages) atau dibuka menggunakan pelayan web tempatan.

2. **`BACA_KOMIK_OFFLINE.html`**
   - Fail HTML kendiri (standalone). Anda boleh klik dua kali fail ini pada Windows / Mac / Chromebook untuk terus membaca koleksi komik dan membuat latihan walaupun tiada sambungan internet!

3. **Kod Sumber Penuh (`src/`, `server.ts`, `vite.config.ts`, `package.json`)**
   - Kod sumber React 19 + TypeScript + Vite + Tailwind CSS yang lengkap untuk pembangunan lanjut.

---

## 🚀 Cara Menjalankan Projek di Komputer Anda (Pembangun)

### Keperluan:
- Pasang [Node.js](https://nodejs.org/) (Versi 18 atau lebih terkini).

### Langkah-langkah:
1. Ekstrak fail ZIP ini ke folder pilihan anda.
2. Buka terminal (Command Prompt / PowerShell / Terminal) di dalam folder tersebut.
3. Pasang kebergantungan pakej:
   ```bash
   npm install
   ```
4. Jalankan aplikasi dalam mod pembangunan:
   ```bash
   npm run dev
   ```
5. Buka pelayar web dan layari:
   ```
   http://localhost:3000
   ```

---

## 🌐 Cara Hoskan Sendiri (Upload ke Web / Vercel / Netlify)
1. Muat naik folder `dist/` ke perkhidmatan hosting seperti Vercel atau Netlify.
2. Atau jalankan pelayan pengeluaran dengan arahan:
   ```bash
   npm start
   ```
